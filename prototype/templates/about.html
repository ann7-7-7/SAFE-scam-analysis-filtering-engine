About S.A.F.E

S.A.F.E is an explainable scam awareness and message-checking tool designed to help users recognise suspicious messages before they click, reply or send money.

What is S.A.F.E?

S.A.F.E stands for Scam Analysis & Filtering Engine. It is a final year cybersecurity project focused on helping users analyse suspicious messages from SMS/Text Message, WhatsApp, Telegram, Email and Social Media DMs. The system provides a scam risk score, detected scam category, warning signs, highlighted red flags and practical safety advice.

Why was S.A.F.E created?

Scam messages are becoming more common and often use urgency, fear, fake links, impersonation and emotional pressure. Many users are unsure whether a message is genuine. S.A.F.E was created to support safer decision-making by helping users pause, check and understand the warning signs.

How does S.A.F.E work?

Paste the message

The user pastes the suspicious message exactly as received.

Detect warning signs

S.A.F.E checks for scam indicators such as urgency, suspicious links, money requests, impersonation, OTP/password requests and unsafe download instructions.

Calculate risk

The system assigns a scam risk score and risk level based on matched indicators.

Explain and advise

The result explains why the message may be suspicious and provides safety guidance.

Current implementation

The current artefact is implemented as an explainable rule-based baseline version of the planned AI-powered scam detection system. It uses predefined scam indicators to demonstrate the complete workflow: message input, scam indicator detection, risk scoring, category identification, explanation and safety advice.

What makes S.A.F.E different?

S.A.F.E focuses on explainability and user education. Instead of only giving a simple safe or unsafe result, it shows a risk score, scam category, matched warning signs, highlighted red flags and practical safety advice.

Future improvements

Supervised NLP model

Train a supervised model such as Logistic Regression or DistilBERT using a larger labelled dataset.

URL checking

Add website link analysis to help identify suspicious or impersonation-style URLs.

Phone number reputation

Explore phone number checking to support scam detection across SMS and messaging platforms.

Image and screenshot analysis

Add support for analysing scam screenshots, fake adverts and image-based messages.

Larger evaluation dataset

Improve testing using more scam and safe examples across different scam categories.

Public deployment after security review

Explore public deployment only after additional security, privacy and reliability testing.

Privacy and ethical approach

S.A.F.E is designed with privacy and user safety in mind. Messages are analysed temporarily and are not stored by default. The system provides risk guidance only and does not guarantee accuracy. Users should always verify suspicious messages through official channels.

Final year cybersecurity project

This website was developed as part of an undergraduate Final Year Project in Cyber Security. The project focuses on phishing, social engineering, scam awareness, explainability, privacy and user-centred security.
